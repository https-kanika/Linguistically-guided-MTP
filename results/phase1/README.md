# results/phase1

Outputs of the first project phase. **Full report: [REPORT.md](REPORT.md)** (generated by `scripts/make_report.py`).

What was done: tokenizer analysis of Hindi; target outputs and draft/target traces for FLORES+ dev and devtest (Llama-3 8B target, 3.2 1B draft); morpheme labels from MorphTok plus a CRF segmenter; a simulator that enforces what a real decoder can know; 13 stopping policies tuned on dev and tested on devtest with bootstrap CIs; a token-level failure analysis; and real speculative decoding on GPU.

Headline (devtest, simulated): confidence rule 1.452× [1.444, 1.461], best fixed length 1.357×, oracle 1.904×. No linguistic policy beats the confidence rule (best: MorphEntropy_ext1 1.427×), and at equal confidence linguistic position does not predict draft failure (change in AUC -0.0001).

Real decoding (100 devtest sentences, wall clock): confidence rule 1.356× over plain decoding, best of all policies. The simulator ranks the policies the same way but is a few percent optimistic (REPORT §10).
