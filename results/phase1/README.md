# results/phase1

Outputs of Phase 1 (`PLAN_phase1_bugfix.md`). **Full report: [REPORT.md](REPORT.md)** (generated by `scripts/make_report.py`).

What was run: tokenizer analysis (T1), 8B/1B traces for FLORES+ dev and devtest on Kaggle (T2), MorphTok gold lexicon + CRF + causal prefix model (T3), causal simulator (T4), 11 policy families tuned on dev and evaluated on devtest with bootstrap CIs (T5–T7), failure analysis (T8), real draft-and-verify loop (T9: done).

Real loop (100 devtest sentences, wall clock): Entropy 1.356× over greedy, best of all policies; the simulator ranks policies the same way but is a few percent optimistic (REPORT §9).

Headline (devtest): Entropy 1.452× [1.444, 1.461], best fixed-k 1.357×, oracle 1.904×; no linguistic policy beats Entropy (best: MorphEntropy_ext1 1.427×), and at equal entropy linguistic position does not predict draft failure (ΔAUC -0.0001).

Caveats: teacher-forcing approximation; lookahead charged (conservative) vs uncharged (optimistic); c = 0.323 measured on 2× T4 with a layer-split target.
